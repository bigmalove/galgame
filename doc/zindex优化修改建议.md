# 数据库界面插件 z-index 优化建议

## 1. 结论摘要

当前层级问题不是单点 bug，而是**层级体系失控**：

- 同时存在多套数值区间：`0~120`、`1000~100002`、`2147483647/2147483648`
- CSS 与 JS 内联样式同时定义 z-index，互相覆盖
- `!important` 使用过多，导致后续修复只能继续“抬高数值”
- 移动端存在历史修补块叠加，出现重复规则与竞态

建议先做**层级收敛**，再做局部修复。

---

## 2. 现状证据（关键点）

### 2.1 CSS 中数值跨度过大

- `#gal-global-overlay.fullscreen`：`z-index: 10000`  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.css:48`
- 弹窗层：`100001 / 100002`  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.css:1172`、`初始模板/脚本/galgame通用生成器/数据库界面插件.css:1268`
- 多处“最高层”使用 `2147483647`  
  位置示例：`初始模板/脚本/galgame通用生成器/数据库界面插件.css:1181`、`初始模板/脚本/galgame通用生成器/数据库界面插件.css:2733`
- 出现 `2147483648`（超 32 位有符号上限）  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.css:2742`

### 2.2 JS 内联样式在“抢层级控制权”

- 自由输入弹窗直接写死：`z-index: 2147483647 !important`  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.js:11508`
- 导入选择弹窗同样写死：`2147483647`  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.js:14209`
- Live2D 设置弹窗写 `100001`  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.js:16399`
- Live2D 位置工具栏写 `100002`，并直接 append 到 `body`  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.js:2560`、`初始模板/脚本/galgame通用生成器/数据库界面插件.js:2630`

### 2.3 结构上已有可利用的正确方向

- 已有统一挂载入口 `getModalMountRoot()`（全屏优先挂载 fullscreenElement）  
  位置：`初始模板/脚本/galgame通用生成器/数据库界面插件.js:10635`

这意味着：可以通过“统一挂载 + 统一 token”解决大部分冲突，不必再靠 max-int。

---

## 3. 主要风险

1. **层级不可预测**：不同弹窗由不同地方注入，数值体系不一致。  
2. **后续维护成本高**：每次新增 UI 都倾向继续抬高 z-index。  
3. **跨端行为不一致**：移动端多个 media block 对同一元素重复强化。  
4. **潜在浏览器边界问题**：`2147483648` 可能被截断/比较异常，导致“以为更高但不一定更高”。

---

## 4. 推荐改造方案（分阶段）

## 阶段 A（建议先做，低风险）

1. 新建统一层级 token（CSS 变量），例如：

```css
:root {
  --gal-z-overlay: 1000;
  --gal-z-dropdown: 1100;
  --gal-z-toast: 1200;
  --gal-z-modal: 2000;
  --gal-z-modal-critical: 2100;
}
```

2. 将以下硬编码值替换为 token：`10000/100000/100001/100002/2147483647/2147483648/9999/1000`。  
3. 先保留 `!important`，但只允许在“跨容器强制覆盖”场景使用（目标是逐步减少，而非一次性全删）。

## 阶段 B（中风险，收益大）

1. 禁止在 JS 模板字符串中写 `z-index`，改为 class：
   - `gal-z-modal`
   - `gal-z-dropdown`
   - `gal-z-toast`
   - `gal-z-critical`
2. 所有弹窗、工具条统一走 `getModalMountRoot()`，不要直接 append 到 `topWindow.document.body`。  
3. Live2D 位置工具栏从“body 注入 + 100002”改为“挂载到 modal root + class 控制”。

## 阶段 C（清理技术债）

1. 合并 `#gal-history-modal` 在移动端的重复修复块（当前 3+ 段规则互相叠加）。  
2. 删除 `2147483648`，统一替换为 token。  
3. 对全屏与非全屏各做一次层级回归清单（弹窗、下拉菜单、toast、导入进度、Live2D 设置）。

---

## 5. 建议的统一层级规范

建议建立并固定以下语义层（仅示例，可按项目调优）：

- `0~99`：场景基础层（背景、角色、对话底层）
- `100~499`：主界面交互层（按钮、状态条）
- `1000~1499`：全屏覆盖层/局部菜单层
- `2000~2499`：标准模态弹窗
- `2500~2999`：关键阻断层（导入进度、全局确认框）

不再使用 “10 万级” 和 “max-int 级”。
