为什么不是方块

P5 的精髓不是「黑白红」，而是「没有一个元素是摆正的」。对话框用不规则 clip-path 剪出毛边，红黑两层垫纸互相错位；底栏十张字条各带 -2.4°～+2.4° 的 随机旋转，像赎金信上剪贴的铅字。悬停时归零回正——混乱是姿态，操作是精准的。

漩涡与网点

无背景图时舞台不再是黑板，而是 repeating-conic-gradient 画出的红黑放射漩涡 （90 秒极慢旋转），中心压暗留给立绘；叠一层半调网点纸模拟印刷质感。有背景图时 整层让位，与现有 .has-bg 机制兼容。

唯一强调色

全界面只有怪盗红一个强调色，黑白负责结构。台词内的强调词可用 红底/黑底白字反转标签（.vox），是 P5 对话里最有记忆点的排印手法。

天鹅绒房间变体

与朱笺「墨夜」同理，变体只覆写 CSS 变量：怪盗红 → 天鹅绒蓝 #2F47D0，墨黑 → 深蓝黑。一套结构两种气质，落地时同样零额外结构成本 （skin-persona-velvet 仅换 token）。
