色彩 · TOKEN

纸、墨、朱砂三色构成，全界面唯一强调色是朱砂红；泥金只用于毫米级细节。夜间变体仅覆写 CSS 变量即可整套换肤，与项目现有 Twilight 变体机制一致。

排印 · 字体

正文与界面统一用 Noto Serif SC（衬线，行高 2.05，两端对齐），拉丁与数字用 Cormorant Garamond 斜体点缀，营造"装帧书页"的阅读感，取代现在的 Barlow 运动感。

层级 · 收敛

原皮肤九个白色斜切按钮全部在争夺注意力。新稿把工具栏降为一行文字按钮（悬停朱线），只允许两个元素发声：NEXT（描边→灌墨）与「抉择之时」（印章脉冲）。

标识 · 记忆点

竖排朱砂印章姓名牌是整套皮肤的签名元素；旁白自动转为墨灰印。顶部地点/时间从深色胶囊改为电影字幕式细线文字，几乎不遮挡画面。
