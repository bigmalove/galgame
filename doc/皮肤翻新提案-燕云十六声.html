01 / SCENE

一幕武侠夜戏

不是"画"，是"戏"：暮雪苍山三叠（雪脊留一线亮），雾纱 26 秒缓掩孤月， 雁阵 70 秒横渡整幅画，两层雪粒风向一致地斜掠，风痕偶尔掠过山谷。 山腰客栈两点暖灯是整幅画唯一的暖色——与 UI 的朱砂互为呼应。 电影颗粒 + 暗角统一收束。

02 / PANEL

墨甲 · 刀裁鎏铜

对话框是一块被刀裁去右上/左下两角的厚重墨甲：鎏铜双线沿形走一圈 （mask-composite 空心描边），裁角处各嵌一枚铜楔（楔心一点玄墨）， 顶缘一线剑寒光七秒缓缓来回。面板右下压一竖行行草题诗水印。 名牌是铜印拓：铜缘深墨牌 + 左侧一方朱砂姓氏小印。

03 / MOTION

剑光与朱砂

交互反馈统一为「剑光扫过」：操作按钮悬停一道寒光横贯，底栏按钮悬停 足下点亮一段朱砂短线，NEXT「出鞘」常驻缓慢剑光。剧情选项是呼吸的朱砂令牌； 「抉择」浮层的令牌自上压下（背景一个巨大的行草"武"字水印）； 生成中是一柄悬剑微颤、剑尖将坠一滴朱砂——「听风」。

04 / ADAPT

雪霁变体 & 移动端

「雪霁」只覆写 CSS 变量：夜墨 → 晨雪青灰，天际透出一线晨金， 铜线转暖、朱砂加深，雪山由剪影转为受光。移动端沿用真实项目紧凑模式 （图标化单行 + 低频键入上拉菜单），山与灯火按竖屏重排， 题字竖排缩短。落地方式与苍穹之庭相同：runtime 注入装饰 DOM + 皮肤 CSS。
