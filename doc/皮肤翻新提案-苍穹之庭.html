01 / SKY

开场 CG 级夜穹

全 CSS 作画：天穹青蓝渐入夜色、地平线一线青辉；极光是竖向光棱 「帘幕」（repeating-linear-gradient 背景位移流动），一等星带十字光轴， 流星每 9/13 秒错峰划落，星尘自云海升腾。右上「天穹之门」—— 极细刻度环缓旋，环心一弯新月，一颗卫星菱晶 16 秒公转。 鼠标移动时星层三速视差。

非对称圣仪面板

03 / MOTION

能量与逐字辉光

NEXT 六角晶键的边框由 @property 驱动 conic-gradient 旋转—— 两束冷暖能量沿边框循环追逐。打字机不再是字符落纸：每个字带 位移 + 辉光 + 模糊三重浮现。立绘身侧有透视压扁的环绕法阵， 选项浮层召唤全幅魔法阵（金刻度外环 / 冰蓝虚线中环 / 符文点内环， 三环反向缓旋，全部 conic-gradient + mask 画成）。

04 / ADAPT

移动端 & 黎明变体

移动端完全对齐真实项目的紧凑模式规则：按钮只显图标、单行均分， 履历/原文/存档/读档收进上拉菜单（demo 中点「设置」即弹出皮肤化的 削角菜单，对应 #gal-mobile-menu），退出排最左，NEXT 固定宽度。 「昼之庭黎明」变体只覆写 CSS 变量组，落地为 skin-jrpg-dawn，零结构成本。
