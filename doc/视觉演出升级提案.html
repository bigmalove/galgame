01 · CAMERA

镜头：漂移 / 视差 / 推镜 / 阻尼震屏

在 .gal-layer-bg、.gal-layer-character、两块 Pixi 画布外各包一层视差容器，一个 rAF 把指针 / deviceorientation 平滑插值后写入 --mx/--my；Ken Burns 放在 .gal-bg-layer 内层，避免和转场的 transform 冲突。说话人切换时 --cam-x 轻推 1.5%。

纯 CSS 变量overlay.js / image-packs.js低成本
02 · TRANSITIONS

转场库 + 先解码再转场

setBackgroundWithTransition(layer, url, {type}) 扩成 6 种；COT 允许 <background scene="…" transition="wipe"/>，场景名换「黑场字幕」做章节感。现状不等图片加载就开播 900ms 动画，远程 2560×1440 图常在动画结束后才硬切出现——先 await img.decode()（带超时）。

修 bugimage-packs.js:471中成本
03 · LIGHTING

背景采样 → 立绘环境光 + 轮廓光

背景切换时把图画到 16×9 画布取平均色、亮度与高光重心，写入 --amb/--rim/--rim-dir；立绘叠两层以自身为 mask 的 multiply / screen 层。替换 applySceneTint 按场景名含「夜」才压暗的关键词判断。跨域图被污染时回退关键词。

立绘不再「贴上去」sprite-manager.js:900中成本
04 · PARTICLES

真·加色发光 + 三层景深

萤火虫 / 余烬给 ParticleContainer 里的子精灵设 ADD，但 Pixi v6 只认容器的 blendMode，发光一直没生效——把 ADD 设到 backLayer/frontLayer。花瓣分远 / 中 / 近三层，近景大而模糊、从对话框前掠过。High 档可加 pixi-filters@4 的 AdvancedBloom / Godray。

修 bugregistry.js:881 / 1010低成本
05 · TYPOGRAPHY

文字节奏：逐字淡入 / 标点停顿 / 行内标签

现状每个字都用 innerHTML 重渲染整段（O(n²)，字是硬跳出来的）。改为一次性切成 span，再逐个加 .on，由 CSS 过渡淡入；句号后停 280ms、逗号停 120ms；支持 {em} {shake} {wave}；打完后显示收尾光标。

性能也更好typewriter.js:188低成本
06 · CHOREOGRAPHY

编排：名牌擦入 / 角色色 / 选项错峰 / CG 揭示

名牌 clip-path 擦入 + 下划条延迟伸出；每个角色派生一个强调色，贯穿名牌、书签角、强调字；选项错峰 70ms 入场并带序号，选中项有确认动画、其余下坠。CG 现在只是换背景，改为闪白→推远聚焦→宽银幕黑边→NEW CG 横幅。弹窗和 toast 补上开场弹簧动画。

overlay-content.js / choices.js / modal.js中成本
07 · FONTS

字体其实一直没加载

默认皮肤的 Barlow / Noto Sans SC，以及各皮肤的 Cinzel、Ma Shan Zheng、Zhi Mang Xing、LXGW WenKai 等都只写进了 font-family，运行时唯一注入的是 Google Fonts 的樱色物语三款（国内基本不可达）。改为按当前皮肤从 jsDelivr fontsource 加载 unicode-range 分片，提案页的观感才能落到线上。

性价比最高styles.js:11926低成本
08 · ASSETS

素材质检：立绘品红残边

日式学园包 103 张立绘里有 22 张左右边缘残留不透明品红条（网格模板的 #FF00FF 分隔线，模型画偏后 1.8% 内缩没切干净，抠图又只去绿）。打包时从边缘连通区域额外剔除品红，或裁掉边缘的品红列。

肉眼可见build-sprite-pack.js:48低成本
