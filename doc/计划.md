# GPT-SoVITS 设置重构计划（仅计划，不改代码）

## 1. 目标与范围

### 1.1 目标
- 移除现有 GPT-SoVITS 复杂设置项，主设置区仅保留：
  - `API地址`
  - `使用酒馆代理`
- 新增「模型管理面板」入口，承载所有 GPT-SoVITS 进阶配置。
- 支持模型的新增、删除、修改、导入（文件夹）与独立编辑。
- 每个模型支持：
  - 配置路径“三大件”
  - 配置参数
  - 参考音频与表情标签映射（按表情切换参考音频）
- 统一视觉风格，保证桌面端 + 移动端易用。

### 1.2 非目标
- 本计划不直接改 `数据库界面插件.js` 功能代码。
- 不改 COT/解析协议，保持 `speaker=...` 逻辑兼容。

---

## 2. 目标交互形态

### 2.1 主设置区（瘦身后）
GPT-SoVITS 区块仅展示：
- `API地址` 输入框
- `使用酒馆代理` 开关
- `打开模型管理` 按钮

### 2.2 模型管理面板（新）
- 入口：点击 `打开模型管理`。
- 面板内容：
  - 顶部工具栏：`新增模型`、`文件夹导入`、`批量导出`、`搜索`
  - 模型列表（卡片或表格）
  - 每项操作：`编辑`、`复制`、`删除`、`试听`
- 每个模型点击 `编辑` 后打开二级编辑面板。

### 2.3 模型编辑面板（新）
- 基础信息：
  - 模型名（自动命名后可改）
  - 备注/描述
  - 启用开关
- 路径三大件：
  - `gptWeightsPath`（ckpt）
  - `sovitsWeightsPath`（pth）
  - `defaultRefAudioPath`（默认参考音频）
- 配置参数：
  - `promptText`
  - `promptLang`
  - `textLang`
  - `textSplitMethod`
  - `speedFactor`
  - `mediaType`
  - `streamingMode`
  - `modelSwitchMode`（set_weights / set_model / none）
  - `setModelEndpoint`（仅 set_model 时显示）
  - `strictWeightSwitch`
- 参考音频映射：
  - 参考音频列表（可多条）
  - 表情标签 -> 参考音频映射表
  - 回退规则：未命中映射时使用 `defaultRefAudioPath`

## 3. 数据结构方案（v2）

```json
{
  "gptSoVits": {
    "apiUrl": "http://127.0.0.1:9880",
    "useCorsProxy": true,
    "models": [
      {
        "id": "model_xxx",
        "name": "景元",
        "enabled": true,
        "desc": "v2ProPlus-景元",
        "paths": {
          "gptWeightsPath": "GPT_weights_v2ProPlus/景元/xxx.ckpt",
          "sovitsWeightsPath": "SoVITS_weights_v2ProPlus/景元/yyy.pth",
          "defaultRefAudioPath": "ref_audio/景元/default.wav"
        },
        "params": {
          "promptText": "",
          "promptLang": "zh",
          "textLang": "zh",
          "textSplitMethod": "cut5",
          "speedFactor": 1,
          "mediaType": "wav",
          "streamingMode": false,
          "modelSwitchMode": "set_weights",
          "setModelEndpoint": "/set_model",
          "strictWeightSwitch": false
        },
        "refAudios": [
          {
            "id": "ref_default",
            "name": "默认",
            "path": "ref_audio/景元/default.wav",
            "promptText": "",
            "promptLang": "zh",
            "textLang": "zh"
          }
        ],
        "expressionRefMap": {
          "开心": "ref_default"
        }
      }
    ]
  }
}
```

### 3.1 兼容迁移策略
- 启动时检测旧字段（如 `voices`、全局 text_lang/speed 等）。
- 自动迁移为 `models[0]` 或按旧音色拆分为多模型。
- 保留一次性迁移标记，避免重复迁移。

## 4. 关键功能设计

### 4.1 表情驱动参考音频切换
- 输入：当前说话段落解析出的 `expression`。
- 选择顺序：
  - `expressionRefMap[expression]` 命中 -> 使用对应参考音频。
  - 未命中 -> 使用 `defaultRefAudioPath`。
- 组装 `/tts` 参数时，参考音频与 prompt 参数以映射命中的 `refAudio` 为准，模型参数为当前模型 `params`。

### 4.2 文件夹导入（自动命名 + 自动填充）
- 入口：模型管理面板 `文件夹导入`。
- 识别规则：
  - 自动扫描 `*.pth`、`*.ckpt`、`*.wav|*.flac|*.ogg|*.mp3`。
  - 模型名优先用权重文件基名（`pth` 优先，其次 `ckpt`），再去噪（去版本后缀等）。
  - `gptWeightsPath` 与 `sovitsWeightsPath` 按同名优先配对，否则按体积/相似度兜底。
  - 自动选一个音频作为 `defaultRefAudioPath`，其余进入 `refAudios`。
  - 尝试从音频文件名推断 `promptText` 与可能的表情词（如 `happy/angry/sad`、中文标签）。
- 导入预览：
  - 显示“将创建/更新”的模型清单。
  - 支持逐条确认与冲突处理（重名覆盖/重命名/跳过）。

### 4.3 运行时模型选择
- 保持 `speaker=模型名` 兼容。
- 通过模型名查找模型配置；找不到时给出明确提示并回退默认模型（可配置）。
- 权重切换沿用现有串行队列逻辑，避免并发争抢。

## 5. UI/UX 与移动端规范

### 5.1 风格统一
- 复用现有 `gal-` 视觉语言（颜色、圆角、阴影、按钮层级）。
- 避免新面板风格割裂：标题、分组、按钮、输入控件与现有设置一致。
- 关键状态可视化：有效/缺失路径、映射冲突、未保存改动。

### 5.2 易用性
- 主设置页只保留两项核心配置，降低认知负担。
- 模型编辑采用分组/标签页，减少长表单滚动。
- 高频操作一键化：`新增`、`导入`、`试听`、`保存`。
- 所有危险操作（二次确认）：删除模型、覆盖导入。

### 5.3 移动端适配
- 模型管理面板在移动端使用全屏抽屉/全屏弹层。
- 底部固定操作栏：`取消`、`保存`、`试听`。
- 列表改为卡片布局，点击热区 >= 40px。
- 控件自适应换行，避免横向滚动。

## 6. 实施分阶段

### 阶段 A：配置收敛与数据迁移
- 收敛主设置项，仅保留 `apiUrl/useCorsProxy`。
- 定义并落地 `models` 新结构。
- 实现旧配置迁移逻辑与容错。

### 阶段 B：模型管理面板（列表层）
- 增加入口与弹层框架。
- 完成模型 CRUD、搜索、排序、基础校验。
- 完成导入预览框架（先不接扫描算法细节）。

### 阶段 C：模型编辑面板（明细层）
- 完成路径三大件编辑。
- 完成参数编辑与联动显示（如 set_model endpoint）。
- 完成参考音频列表与表情映射编辑器。

### 阶段 D：文件夹导入算法
- 实现扫描、命名、配对、自动填充。
- 实现重名冲突策略与导入结果提示。
- 覆盖典型目录结构与异常样例。

### 阶段 E：运行时接入与回归
- 将 TTS 请求改为从新模型结构取值。
- 接入“按表情切换参考音频”逻辑。
- 回归验证 COT、默认音色、并发播放、报错提示。

### 阶段 F：UI 抛光与移动端验收
- 统一样式细节、加载状态、空状态。
- 完成移动端可用性调优与触控优化。

## 7. 验收清单
- 主设置区仅有 `API地址`、`使用酒馆代理` 和 `打开模型管理`。
- 可在模型管理面板完成模型新增/删除/修改/复制/试听。
- 每个模型可独立维护路径三大件和参数。
- 支持参考音频列表与“表情标签 -> 参考音频”映射。
- 播放时可根据表情自动切换参考音频。
- 文件夹导入可自动命名并自动填充关联文件。
- 桌面端与移动端都可顺畅操作，视觉风格统一。
