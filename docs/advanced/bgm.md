# 背景音乐 (BGM)

## 工作原理

AI 在输出中使用 `<bgm>` 标签指定音乐名称，插件会自动在线搜索并播放匹配的音乐。

例如，AI 输出 `<bgm>夜晚的雨声</bgm>`，插件会搜索相关音乐并播放。

## BGM 白名单

你可以在 **设置面板** 中配置 BGM 白名单——限制 AI 只能从指定的歌单中选择音乐：

1. 打开设置面板
2. 找到「BGM 白名单」
3. 添加允许的歌曲名称
4. 注入世界书后，AI 将只从白名单中选择 BGM

::: info
如果不设置白名单，AI 会根据剧情自由选择真实存在的音乐名称。
:::

## 播放控制

- **播放/暂停**：点击工具栏的 BGM 按钮
- **音量调节**：在设置面板中拖动音量滑块
- **暂停记忆**：如果你主动暂停 BGM，在你手动恢复之前不会自动播放新 BGM
