# 视觉特效

## 特效列表

插件基于 PixiJS 提供以下实时粒子特效：

| 特效名 | 效果 | 适用场景 |
|---|---|---|
| `rain` | 🌧️ 雨 | 雨天、忧郁场景 |
| `snow` | ❄️ 雪 | 冬天、宁静场景 |
| `heavySnow` | 🌨️ 大雪 | 暴风雪、严寒场景 |
| `cherryBlossoms` | 🌸 樱花飘落 | 春天、浪漫场景 |
| `fog` | 🌫️ 雾 | 神秘、恐怖场景 |
| `fireflies` | ✨ 萤火虫 | 夜晚、梦幻场景 |
| `embers` | 🔥 余烬 | 战斗、火灾场景 |
| `screenFlash` | ⚡ 闪屏 | 爆炸、雷电、强光 |

## AI 自动触发

注入 COT 世界书后，AI 会根据剧情氛围在输出中自动插入特效标签。例如：

- 下雨场景 → 自动触发 `rain` 特效
- 樱花树下 → 自动触发 `cherryBlossoms` 特效

## 特效设置

在设置面板的「Pixi特效」区域中可以配置：

| 设置项 | 说明 | 选项/范围 |
|---|---|---|
| **启用特效** | 总开关 | 开/关 |
| **质量档位** | 粒子数量与渲染质量 | Mobile（省电）/ Balanced（默认）/ High（高画质） |
| **切场景自动清空** | 场景切换时是否自动清除当前特效 | 开/关（默认开） |
| **并发上限** | 同时运行的特效数量上限 | 1~6（默认 2） |

::: tip 质量档位说明
- **Mobile**：粒子数量最少，适合低配设备和移动端
- **Balanced**：推荐设置，在效果和性能之间取得平衡
- **High**：粒子数量最多，效果最佳，对设备性能要求较高
:::

## 手动控制（进阶）

你也可以通过浏览器控制台手动控制特效：

```javascript
// 播放特效
galgame.effects.play('rain')

// 清除所有特效
galgame.effects.clear()

// 查看当前状态
galgame.effects.state()

// 设置并发上限 (1-6)
galgame.effects.maxActive(3)
```
