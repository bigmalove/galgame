# 加强模式

## 什么是加强模式

加强模式（Enhanced Mode）是为了解决 **AI 不能稳定输出 Galgame 格式** 的问题而设计的。

正常情况下，AI 需要同时完成两件事：
1. 创作故事内容
2. 按 Galgame 标签格式输出

部分模型在这两件事之间顾此失彼。加强模式将它们拆分为 **两次生成**：

| 步骤 | 任务 |
|---|---|
| **第一次生成** | AI 专注于创作故事内容（可以不遵循格式） |
| **第二次生成** | 插件自动将故事内容发给 AI，要求格式化为 Galgame 标签 |

## 启用加强模式

1. 打开 **设置面板**
2. 找到「加强模式」区域
3. 开启后，配置第二次生成的参数

## 配置项

### 连接与模型配置

每个配置项都可以单独勾选启用：

| 配置 | 说明 |
|---|---|
| **连接配置** | 第二次生成使用的 API 连接配置（Profile） |
| **模型** | 第二次生成使用的模型（可选不同的格式化专用模型） |
| **预设** | 第二次生成使用的采样预设（Preset） |

::: tip 推荐
第二次生成可以使用较便宜/较快的模型，因为它只需要做格式化，不需要创作能力。
:::

### 世界书设置

加强模式为第二次生成提供三种世界书策略：

| 模式 | 说明 |
|---|---|
| **不使用自定义世界书（默认）** | 使用当前全局启用的世界书 |
| **不使用任何世界书** | 第二次生成时禁用所有世界书 |
| **使用指定世界书** | 从列表中勾选要在第二次生成时启用的世界书 |

### 查看提示词

点击「查看提示词」按钮可以查看加强模式最近一次生成使用的完整提示词，包括：

- **System Prompt**：系统提示词
- **First Result**：第一次生成的原始结果
- **User Prompt**：发给第二次生成的用户提示词

这对调试格式化效果非常有用。

## 使用流程

1. 开启加强模式
2. 正常发送消息
3. AI 先完成第一次生成（内容创作）
4. 插件自动触发第二次生成（格式化）
5. 覆盖层上会有进度提示
6. 最终以 Galgame 格式展示结果
