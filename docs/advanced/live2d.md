# Live2D 角色模型

## 什么是 Live2D

Live2D 是一种让 2D 角色动起来的技术。插件支持直接在 Galgame 覆盖层中展示 Live2D 模型，让角色拥有呼吸、眨眼、表情变化等动态效果。

支持的模型格式：
- Cubism 2（旧版 `.moc` 格式）
- Cubism 4（`.moc3` 格式）
- Cubism 5（最新版 `.moc3` 格式）

## 添加 Live2D 模型

### 本地上传

1. 打开 **设置面板** → **Live2D 设置**
2. 选择要绑定的角色名
3. 点击 **上传模型**
4. 选择模型文件夹（包含 `.model3.json` 或 `.model.json`）

### 从远程 URL 加载

1. 在 Live2D 设置中选择角色
2. 选择「远程」来源
3. 填入模型的 `model3.json` 完整 URL
4. 插件会自动下载并缓存模型

### 在线模型库

1. 在 Live2D 设置中点击 **浏览在线模型库**
2. 浏览可用的模型
3. 点击即可导入

## 调整位置和缩放

插件提供 **可视化位置编辑器**：

1. 在 Live2D 设置中点击 **调整位置**
2. 拖拽模型调整位置
3. 使用缩放滑块调整大小
4. 选择槽位（左 / 中 / 右）
5. 确认保存

## 表情与动作

插件会将 AI 输出中的表情标签自动映射到 Live2D 模型的表情和动作：

| AI 输出表情 | Live2D 行为 |
|---|---|
| 微笑 | 切换到开心表情 |
| 生气 | 切换到生气表情 |
| 难过 | 切换到悲伤表情 |
| ... | 自动匹配 |

## 口型同步

当 TTS（语音合成）播放角色语音时，Live2D 模型可以同步移动嘴部：

1. 确保已启用 TTS
2. 在 Live2D 设置中启用口型同步
3. 角色说话时，模型的嘴巴会随音频同步运动
