# 地图系统

## 功能概述

地图系统让你可以在一张背景地图上标记剧情中出现的各个地点，直观地展示角色所在位置。

## 打开地图

点击工具栏的 **地图** 按钮（🗺️），即可打开地图面板。

## 设置地图

### 上传地图背景

1. 在地图面板中点击 **上传地图**
2. 选择一张地图图片
3. 图片将作为地图的底图显示

### 管理地点标记

1. 进入 **编辑模式**
2. 在地图上点击想要标记的位置
3. 输入地点名称
4. 标记会显示在地图上

你可以：
- ✏️ 编辑地点名称和坐标
- 🗑️ 删除地点标记
- 📋 复制地点坐标

### 标记样式

在设置中可以选择标记的显示样式（图钉等）。

## 地图交互

- 点击地图上的标记可查看地点详情
- 当前位置会高亮显示
