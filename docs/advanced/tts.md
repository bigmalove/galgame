# 语音合成 (TTS)

## 支持的引擎

| 引擎 | 说明 | 适合场景 |
|---|---|---|
| **小白盒 (LittleWhiteBox)** | 默认引擎，开箱即用 | 快速体验 |
| **GPT-SoVITS** | 本地语音合成引擎，音质更高 | 追求高品质 |

## 基本设置

在 **设置面板** → **音频设置** 中：

1. **启用/禁用 TTS**：总开关
2. **自动播放**：是否在每段对话后自动播放语音
3. **角色-音色绑定**：为每个角色指定专属音色

## 角色音色绑定

1. 在音频设置中找到「角色音色」
2. 选择角色名
3. 从音色列表中选择合适的音色
4. 保存后，该角色的所有对话都会使用绑定的音色

::: tip
绑定信息会自动反映到 COT 世界书中，AI 也会在输出中遵守音色分配。
:::

## GPT-SoVITS 配置

如果你本地运行了 GPT-SoVITS 语音服务：

1. **API 地址**：填写服务地址（默认 `http://127.0.0.1:9880`）
2. **代理设置**：如需跨域访问，启用 CORS 代理
3. **模型管理**：添加/切换参考音频模型
4. **语速调节**：控制语音播放速度
5. **流式模式**：启用流式传输以减少延迟
6. **语言设置**：选择文本语言（自动/中/英/日等）

## 与 Live2D 口型联动

当同时启用 TTS 和 Live2D 时，角色说话的语音会驱动 Live2D 模型的口型同步动画。详见 [Live2D 章节](/advanced/live2d#口型同步)。
