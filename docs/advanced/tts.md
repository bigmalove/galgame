# 语音合成 (TTS)

## 支持的引擎

| 引擎 | 说明 | 适合场景 |
|---|---|---|
| **小白X（豆包火山）** | 默认引擎，开箱即用 | 快速体验 |
| **GPT-SoVITS v2ProPlus** | 本地语音合成引擎，音质更高 | 追求高品质 |

## 基本设置

在 **设置面板** → **TTS配音** 区域中：

1. **启用/禁用 TTS**：总开关，开启后对话格式会包含 TTS 属性（表情在开头），关闭则使用简单对话格式（表情在结尾）
2. **自动播放**：是否在每段对话后自动播放语音
3. **默认音色**：未指定/未绑定时使用的默认音色

::: info TTS 对输出格式的影响
开启 TTS 时，AI 输出格式为 `角色名[表情,音色]: "对话"` 或 `角色名[表情|语气描述]: "对话"`。
关闭 TTS 时，AI 输出格式为 `角色名: "对话"<表情名>`。
:::

## GPT-SoVITS 配置

如果你本地运行了 GPT-SoVITS 语音服务（api_v2.py）：

### 基础配置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| **API 地址** | 服务地址 | `http://127.0.0.1:9880` |
| **使用酒馆代理** | 通过 SillyTavern 代理解决跨域 | 开启 |

### 模型管理

| 设置项 | 说明 |
|---|---|
| **模型切换模式** | `set_weights`（api_v2.py）/ `set_model`（api.py）/ `none`（不自动切换） |
| **set_model 接口** | 自定义 set_model 端点路径（默认 `/set_model`） |
| **严格切换** | 模型切换失败时是否不回退 |
| **模型管理面板** | 可视化管理 GPT-SoVITS 模型和参考音频 |

### 模型管理面板

点击设置面板中的 **「打开管理面板」** 按钮即可打开 GPT-SoVITS 模型管理器。面板提供两种方式添加模型：

- **新增模型**：手动填写模型路径和参考音频
- **文件夹导入**：从本地文件夹自动识别并批量导入模型（推荐 ✨）

---

### 文件夹导入（推荐）

文件夹导入是最便捷的模型配置方式，只需将模型文件按照规范的目录结构组织好，即可一键导入。

#### 第一步：准备文件夹结构

在你的 GPT-SoVITS 安装目录（或任意位置）中，为每个角色/音色创建独立的文件夹：

![角色文件夹结构示例](/images/tts-folder-structure.png)

```
GPT-SoVITS v2 pro plus/
├── 丰川祥子（白祥）/
│   ├── Mujica_丰川祥子_白_v2pp.ckpt      ← GPT 模型权重
│   ├── Mujica_丰川祥子_白_v2pp.pth       ← SoVITS 模型权重
│   └── (A)あなたと空を見上げるのは、いつも夏でしたわね.wav  ← 参考音频
├── 丰川祥子（黑祥）/
│   ├── ...
├── 海铃/
│   ├── ...
├── 喵梦_乖猫/
│   ├── ...
└── ...
```

::: warning 文件夹命名即音色名
文件夹的名称会被用作导入后的 **模型名称 / 音色名称**。建议使用有意义的命名，如 `角色名_情绪` 或 `角色名（别名）` 的格式。
:::

#### 每个文件夹的要求

每个角色文件夹内 **必须** 包含以下文件：

![单个角色文件夹内容示例](/images/tts-folder-contents.png)

| 文件类型 | 数量 | 说明 |
|---|---|---|
| `.ckpt` 文件 | **1 个** | GPT 模型权重文件（通常较大，~148 MB） |
| `.pth` 文件 | **1 个** | SoVITS 模型权重文件（通常较大，~164 MB） |
| `.wav` 文件 | **至少 1 个** | 参考音频（第一个 `.wav` 文件将作为默认参考音频） |

::: tip 参考音频说明
- 参考音频用于指导模型的语音风格和音色
- 建议使用 3~10 秒的清晰语音片段
- 如果文件夹中有多个 `.wav` 文件，它们都会被识别为参考音频
- 第一个（按文件名排序）`.wav` 文件会被设为 **默认参考音频**
:::

#### 第二步：导入文件夹

1. 打开 **设置面板** → **TTS配音** → 点击 **「打开管理面板」**
2. 在管理面板中点击 **「📁 文件夹导入」** 按钮
3. 在弹出的文件选择器中，选择包含模型文件的 **角色文件夹**（或包含多个角色文件夹的 **父文件夹**）
4. 插件会自动扫描文件夹，识别 `.ckpt`、`.pth` 和 `.wav` 文件
5. 导入完成后，模型会显示在管理面板的列表中

::: info 批量导入
如果选择的是一个包含多个角色文件夹的父目录，所有符合要求的子文件夹都会被一次性导入。
:::

::: danger ⚠️ 路径必须正确！
导入后的模型配置中保存的是文件的 **绝对路径**。请务必确保：

1. **模型文件不要移动或重命名** —— 导入后如果移动了 `.ckpt`、`.pth` 或 `.wav` 文件的位置，模型将无法正常加载
2. **路径中不要包含特殊字符** —— 尽量避免路径中出现 `#`、`%`、`&` 等特殊字符
3. **GPT-SoVITS 服务必须能访问该路径** —— 如果 GPT-SoVITS 运行在 Docker 或其他隔离环境中，需确保路径已正确映射
4. **注意盘符和大小写** —— Windows 下盘符（如 `I:/`）需与 GPT-SoVITS 服务实际识别的路径一致

如果语音无法正常合成，请首先在模型管理面板中检查 CKPT、PTH 和参考音频的路径是否指向了实际存在的文件。
:::

#### 第三步：管理已导入的模型

导入完成后，每个模型卡片会显示以下信息：

![模型管理面板示例](/images/tts-model-panel.png)

- **模型名称**：来自文件夹名（可编辑）
- **导入方式**：标注为「文件夹导入」
- **参考音频数量**：识别到的 `.wav` 文件数
- **CKPT 路径**：GPT 模型文件的完整路径
- **PTH 路径**：SoVITS 模型文件的完整路径
- **默认参考**：默认参考音频的完整路径

对每个模型可以执行以下操作：

| 操作 | 说明 |
|---|---|
| **✏️ 编辑** | 修改模型名称、路径、参考音频等配置 |
| **▶️ 试听** | 使用当前配置合成一段测试语音 |
| **📋 复制** | 复制当前模型配置为新模型 |
| **⭐ 设为默认** | 将此模型设为默认使用 |
| **🗑️ 删除** | 删除此模型配置（不会删除实际文件） |

::: tip 启用模型
导入后记得点击 **「设为默认」** 或在音色绑定中指定该模型，否则不会被使用。模型卡片右上角会显示绿色的「已启用」标签表示当前活跃模型。
:::

### 手动添加音色

除文件夹导入外，也可以通过 **「+ 新增模型」** 手动添加，或在设置面板中通过 JSON 编辑器直接编辑音色列表。每个音色需要包含：

```json
[
  {
    "name": "示例音色",
    "refAudioPath": "wavs/xxx.wav",
    "promptText": "示例参考文本",
    "promptLang": "zh"
  }
]
```

配置完成后点击「保存音色列表」，插件会自动更新 COT 世界书中的音色信息。

你也可以使用「试听」功能测试音色效果。

## 与 Live2D 口型联动

当同时启用 TTS 和 Live2D 时，角色说话的语音会驱动 Live2D 模型的口型同步动画。详见 [Live2D 章节](/advanced/live2d#口型同步)。
