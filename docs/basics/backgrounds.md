# 背景与场景

## 背景图来源

插件支持多种背景图来源，可在设置面板的「资源管理」→「生图配置」中切换：

| 来源 | 说明 |
|---|---|
| **无（本地图库）** | 使用手动上传到资源管理器中的背景图 |
| **ComfyUI** | 连接本地 ComfyUI，AI 根据剧情实时生成背景 |
| **大香蕉 (Banana)** | 使用大香蕉 AI 生图服务，支持 CG 模式和角色外貌描述 |
| **NovelAI** | 使用 NovelAI 的图像生成 API（支持 nai-diffusion-4-5-curated 等模型） |
| **Wallhaven** | 从 Wallhaven 壁纸库搜索匹配背景（支持 SFW/Sketchy 过滤、动漫分类、自定义标签） |

::: info 最简单的方式
**零配置起步**：资源管理器 → 导入 → [内置背景图包](/resources/builtin-bg-packs)，一键导入日式学园 / 仙侠 / 古装 / 现代都市四套 2K 背景。也可以手动上传背景图，AI 会从已有图库中选择匹配的场景。
:::

### 大香蕉 (Banana) 配置

| 设置项 | 说明 |
|---|---|
| 代理地址 / API Key | 服务连接配置 |
| 模型 | 选择使用的生图模型 |
| CG 模式 | 开启后生成角色+场景 CG，关闭则仅生成场景背景 |
| CG 图片尺寸 | CG 模式下的图片比例 |
| 角色外貌描述 | 配置角色的外貌 tag，用于 CG 模式 |
| COT 模板 | 自定义生图提示词模板 |
| 默认前/后缀 | 自动添加到生图提示词的前后缀 |
| 自动保存到图库 | 生成的背景图自动存入本地图库 |

### NovelAI 配置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| API Key | NovelAI API 密钥 | — |
| 模型 | 生图模型 | nai-diffusion-4-5-curated |
| 宽度 × 高度 | 图片尺寸 | 1216 × 832 |
| Scale | CFG Scale | 10 |
| 采样器 | 采样方法 | k_euler |
| 步数 | 采样步数 | 28 |
| Noise Schedule | 噪声调度 | karras |
| 负面提示词 | 排除不想要的元素 | 预设常见排除词 |
| 默认前/后缀 | 自动添加到提示词 | masterpiece, best quality... |
| 自动保存到图库 | 生成的图片自动存入本地图库 | 开启 |

### Wallhaven 配置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| Purity | 内容过滤级别（SFW/Sketchy） | SFW |
| CG 模式 | 搜索角色+场景图，而非仅场景 | 关闭 |
| Category | 图片分类（Anime/General/People） | Anime |
| 自定义标签 | 额外搜索标签 | — |
| API Key | Wallhaven API 密钥（可选，用于高级搜索） | — |

## 背景切换

当 AI 输出中包含场景变化时，背景会自动切换，并带有平滑的过渡动画。

## 场景色调

插件会根据剧情中的时间氛围自动调整画面色调：

- ☀️ 白天 —— 明亮色调
- 🌅 黄昏 —— 暖橙色调
- 🌙 夜晚 —— 偏蓝暗色调

## 填充模式

在设置面板中可以切换背景图的填充方式：

- **Cover**：背景图铺满整个画面（可能裁切边缘）
- **Contain**：完整显示背景图（可能留有黑边）
