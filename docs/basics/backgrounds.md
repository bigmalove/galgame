# 背景与场景

## 背景图来源

插件支持多种背景图来源，可在设置面板的「生图配置」中切换：

| 来源 | 说明 |
|---|---|
| **本地图库** | 使用手动上传到资源管理器中的背景图 |
| **ComfyUI** | 连接本地 ComfyUI，AI 根据剧情实时生成背景 |
| **大香蕉 (Banana)** | 使用大香蕉 AI 生图服务生成背景 |
| **NovelAI** | 使用 NovelAI 的图像生成 API |
| **Wallhaven** | 从 Wallhaven 壁纸库搜索匹配背景 |

::: info 最简单的方式
如果你不想配置 AI 生图，只需在资源管理器中手动上传背景图，AI 会从已有图库中选择匹配的场景。
:::

## 背景切换

当 AI 输出中包含场景变化时，背景会自动切换，并带有平滑的过渡动画。

## 场景色调

插件会根据剧情中的时间氛围自动调整画面色调：

- ☀️ 白天 —— 明亮色调
- 🌅 黄昏 —— 暖橙色调
- 🌙 夜晚 —— 偏蓝暗色调

## 填充模式

在设置面板中可以切换背景图的填充方式：

- **Cover**：背景图铺满整个画面（可能裁切边缘）
- **Contain**：完整显示背景图（可能留有黑边）
