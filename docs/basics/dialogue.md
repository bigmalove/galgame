# 对话与文本

## AI 输出如何变成 Galgame 格式

当插件启用并注入了 COT 世界书后，AI 会按照特定的标签格式输出内容。插件的解析器会自动将这些标签渲染为 Galgame 界面元素。

你不需要关心标签的具体语法——只需注入世界书，AI 就会自动输出正确的格式。

## 逐段推进对话

AI 的每条回复可能包含多段对话。插件会将它们分段展示：

1. 第一段对话自动显示
2. 点击覆盖层空白区域或「下一步」按钮，显示下一段
3. 直到所有段落展示完毕

::: tip
你也可以快速点击跳过动画，直接显示当前段落的完整文本。
:::

## 角色对话与旁白

插件会区分两种文本类型：

- **角色对话**：显示角色名 + 带引号的对话，并附带表情变化
- **旁白**：直接显示描述性文本，不带角色名

## 文字特效

在设置面板的「显示设置」中，你可以为文字选择不同的渲染样式，以适应不同明暗的背景并提高阅读体验：

| 特效 | 说明 |
|---|---|
| **无** | 默认直接带阴影显示文字 |
| **阴影增强** | 增加文字背后的深色阴影范围，使其在亮色背景上更清晰清晰 |
| **发光效果** | 给文字添加向外发光效果 |
| **文字描边** | 让每一个文字边缘产生深色或白色的明显描边 |
| **毛玻璃背景** | 让对话框文本区域出现一层磨砂玻璃质感的背景 |
| **底部渐变遮盖** | 在对话框最底部加上渐变变暗的遮罩，使白色文字显示更突出 |
| **独立文字背景** | 字幕样式的独立底色块文字 |

## 字号与透明度

在设置面板的「显示设置」中可以调节：

- **字号大小**：调整对话文字的大小
- **对话框透明度**：调整对话框背景的透明程度
