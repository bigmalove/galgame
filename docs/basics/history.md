# 剧情回顾

点击工具栏的 **LOG** 按钮（📖），打开剧情回顾面板。面板右上角有两个页签：**对话记录** 和 **剧情纪要**。

## 对话记录

按楼层列出你已经读过的内容：

- 📝 **旁白与对白**：当前楼层只列到正在显示的这一段，之后的段落不会提前剧透
- 💬 **玩家发言**：你选择的选项或输入的内容，单独显示为一张卡片
- 🔊 **语音按钮**（开启 TTS 时）：每句对白前都有
  - **实心**：已经缓存，点击立即播放
  - **空心**：还没有缓存，点击会先合成再播放，播放后自动变为实心
  - 播放中再点一次则停止

::: tip
对话记录只包含酒馆当前已加载的楼层（最多 60 个）。语音缓存的说明见 [语音合成 → 语音缓存与重播](/advanced/tts#语音缓存与重播)。
:::

## 剧情纪要

显示从数据库总结表读取的剧情摘要，包含：

- 📝 **剧情编号**
- 🕐 **时间跨度**
- 📖 **剧情纪要**

### 数据来源

剧情纪要从「AutoCardUpdater」数据库的「总结表」中自动读取。如果你的角色卡配合了数据库系统，这里会自动填充。

::: info
如果总结表为空或未配置数据库，会显示「暂无剧情纪要」。没有对话记录时，面板会直接打开剧情纪要页签。
:::
