# 角色立绘

## 什么是立绘

立绘是角色的半身/全身图片，显示在 Galgame 覆盖层的左右两侧。当 AI 输出中提到角色及其表情时，对应的立绘会自动展示和切换。

## 上传立绘

### 单张上传

1. 打开 **资源管理器**
2. 进入 **立绘** 分类
3. 点击 **上传** 按钮
4. 选择角色名并指定表情类型
5. 选择图片文件（推荐透明背景 PNG）

### 批量上传

1. 在资源管理器中选择 **批量上传**
2. 一次选择多张图片
3. 插件会自动为每张图分配角色名和表情

::: tip 推荐规格
- 格式：PNG（透明背景）
- 分辨率：建议宽度 512px 以上
:::

## 表情差分

插件内置以下表情类型：

`默认`、`微笑`、`生气`、`难过`、`惊讶`、`嘲讽`、`害羞`、`思考`、`大笑`、`搞怪`

你也可以通过资源管理器添加自定义表情名称。

AI 在输出对话时会附带表情标签，插件会自动切换到对应的表情立绘。

## 多角色同屏

插件支持同时显示两个角色（左/右槽位）：

- 当前说话的角色会高亮显示
- 非说话角色会略微变暗
- 当新角色出场时，最旧的非主角角色会自动退场

## 立绘设置

在设置面板的「立绘设置」区域可以调节：

| 设置项 | 说明 | 范围 |
|---|---|---|
| **立绘大小** | 调整立绘整体缩放 | 50%~150%（默认 100%） |
| **垂直位置** | 调整立绘底部偏移 | 0%~50%（默认 20%） |
| **立绘间距** | 调整左右角色之间的距离 | 0%~20%（默认 20%） |

## 说话者效果

在设置面板中还可以开关两种说话者视觉效果：

| 效果 | 说明 | 默认 |
|---|---|---|
| **说话者光晕** | 当前说话角色立绘周围出现发光轮廓 | 开启 |
| **气泡指示器** | 漫画风格的对话气泡指向当前说话角色 | 开启 |

## 入场与退场动画

角色出场和退场时会有平滑的滑入/滑出动画效果。
