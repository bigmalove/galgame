# 角色立绘

## 什么是立绘

立绘是角色的半身/全身图片，显示在 Galgame 覆盖层的左右两侧。当 AI 输出中提到角色及其表情时，对应的立绘会自动展示和切换。

## 上传立绘

### 单张上传

1. 打开 **资源管理器**
2. 进入 **立绘** 分类
3. 点击 **上传** 按钮
4. 选择角色名并指定表情类型
5. 选择图片文件（推荐透明背景 PNG）

### 批量上传

1. 在资源管理器中选择 **批量上传**
2. 一次选择多张图片
3. 插件会自动为每张图分配角色名和表情

::: tip 推荐规格
- 格式：PNG（透明背景）
- 分辨率：建议宽度 512px 以上
:::

## 表情差分

插件内置以下表情类型：

`默认`、`微笑`、`生气`、`难过`、`惊讶`、`嘲讽`、`害羞`、`思考`、`大笑`、`搞怪`

你也可以通过资源管理器添加自定义表情名称。

AI 在输出对话时会附带表情标签，插件会自动切换到对应的表情立绘。

## 多角色同屏

插件支持同时显示两个角色（左/右槽位）：

- 当前说话的角色会高亮显示
- 非说话角色会略微变暗
- 当新角色出场时，最旧的非主角角色会自动退场

## 入场与退场动画

角色出场和退场时会有平滑的滑入/滑出动画效果。
