# 导出角色卡

## 导出为 PNG 角色卡

这是推荐的分发方式——导出的 PNG 文件里包含了完整的角色卡数据 + 插件配置，用户导入即可使用。

### 操作步骤

1. 打开 **资源管理器**
2. 点击顶部的 **导出** 按钮
3. 选择 **「导出角色卡 PNG」**
4. 插件会自动将以下配置嵌入到角色卡中：
   - 📦 资源包配置（远程图包地址）
   - 💃 Live2D 模型绑定（URL + 位置/缩放）
   - 🔊 TTS 角色音色绑定
   - 🎵 BGM 白名单
5. 下载生成的 PNG 文件

::: tip
导出的 PNG 文件就是最终分发物——直接分享给用户即可。
:::

## 远程资源托管

由于角色卡 PNG 的体积有限，立绘、背景等图片资源通常不会直接嵌入卡中，而是存储在远程服务器上。

### 为什么需要远程托管

- 角色卡 PNG 容量有限，无法存放大量高清图片
- 远程托管让用户导入后 **按需加载**，不影响导入速度
- 更新资源时只需更新远程文件，无需重新导出角色卡

### 使用 GitHub 托管（推荐免费方案）

1. **创建 GitHub 仓库**，上传你的资源文件
2. 在资源管理器中，点击 **导出** → **导出远程资源包**
3. 将生成的 `remote_assets.json` 也上传到仓库
4. 回到资源管理器，在远程地址配置中填写你的 **GitHub 仓库地址**
   - 格式：`https://github.com/你的用户名/仓库名`
   - 插件会自动将 GitHub 地址转换为 jsDelivr CDN 加速链接
5. 重新 **导出角色卡 PNG**，远程地址会一并嵌入

### 仓库目录结构建议

```
你的仓库/
├── remote_assets.json    ← 资源索引文件
├── sprites/              ← 立绘图片
│   ├── 角色名_默认.png
│   ├── 角色名_微笑.png
│   └── ...
├── backgrounds/          ← 背景图片
│   ├── 教室.png
│   ├── 公园.png
│   └── ...
└── live2d/               ← Live2D 模型（可选）
    └── 角色名/
        ├── model3.json
        └── ...
```
