# 配置你的角色卡

::: tip 前提
确保你已经安装了 Galgame 界面插件，并且当前打开了你要配置的角色卡聊天界面。
:::

## 第一步：上传资源

### 上传角色立绘

1. 点击 Galgame 按钮打开覆盖层
2. 打开 **设置面板** → 进入 **资源管理器**
3. 选择 **立绘** 分类
4. 点击 **上传**，选择角色立绘图片

::: tip 批量上传
如果你有多张表情差分图，使用 **批量上传** 功能一次完成。插件会自动分配表情类型。
:::

**立绘推荐规格**：
- 格式：PNG（透明背景）
- 分辨率：宽度 512px 以上

### 上传背景图

1. 在资源管理器中选择 **背景** 分类
2. 点击 **上传**，为每张图命名场景名称（如「教室」「公园」「夜晚街道」）

<!-- ![上传背景示例](../public/images/card-author-bg-upload.png) -->

### 添加 Live2D 模型（可选）

1. 打开 **设置面板** → **Live2D 设置**
2. 选择角色名 → 添加 Live2D 模型（本地上传或填写远程 URL）
3. 使用 **位置编辑器** 拖拽调整模型的位置和大小
4. 选择模型的显示槽位（左/右）

<!-- ![Live2D 位置编辑器](../public/images/card-author-live2d-editor.png) -->

## 第二步：绑定设置

### TTS 音色绑定

1. 打开 **设置面板** → **音频设置**
2. 在「角色音色」区域，为每个角色选择合适的音色
3. 保存

### BGM 白名单（可选）

1. 在设置面板中找到「BGM 白名单」
2. 添加你推荐的背景音乐名称
3. AI 将只从白名单中选择 BGM

### 选择皮肤（可选）

1. 在「显示设置」中选择合适的界面皮肤
2. 选择与你角色卡风格搭配的主题

## 第三步：注入世界书

1. 在设置面板中点击 **「注入世界书」** 按钮
2. 插件会自动生成 COT 格式规范，内容包含：
   - 你上传的所有表情名称
   - 你上传的所有场景名称
   - TTS 音色列表和角色绑定
   - BGM 白名单
3. 世界书会全局启用

::: warning 重要
每次修改资源后（增删立绘/背景/音色），都建议重新点击「注入世界书」以更新格式规范。
:::

## 第四步：测试

1. 发送一条消息给 AI
2. 检查以下内容是否正常：
   - ✅ Galgame 覆盖层正常显示
   - ✅ AI 按格式输出对话和旁白
   - ✅ 立绘正确显示并随表情切换
   - ✅ 背景正确加载
   - ✅ TTS 语音正常播放（如已启用）
   - ✅ Live2D 正常展示（如已添加）

一切正常？进入 [第二步：导出角色卡](/card-author/export)。
