# 验证与分发

## 自测流程

在分发角色卡之前，请完成以下检查：

### 准备测试环境

最佳做法是找一个 **干净的酒馆环境** 进行测试（或请朋友帮忙测试），确保没有残留的本地配置干扰结果。

### 测试清单

| # | 检查项 | 预期结果 |
|---|---|---|
| 1 | 导入角色卡 PNG | 角色卡正常导入，无报错 |
| 2 | 开启插件 | Galgame 覆盖层正常显示 |
| 3 | 立绘加载 | 从远程自动加载立绘，角色图片正常显示 |
| 4 | 背景加载 | 背景图从远程加载并显示 |
| 5 | Live2D 显示 | 模型正确加载，位置/缩放符合预期 |
| 6 | TTS 音色 | 角色使用绑定的音色说话 |
| 7 | 发送消息 | AI 按 Galgame 格式输出，界面正常渲染 |
| 8 | 表情切换 | 立绘/Live2D 随对话表情变化 |

## 分发你的角色卡

验证通过后，你可以将导出的 **PNG 角色卡文件** 分享给用户。

### 用户需要什么

用户只需要：
1. ✅ 安装 SillyTavern + 酒馆助手
2. ✅ 安装 Galgame 界面插件脚本
3. ✅ 导入你的角色卡 PNG
4. 🎉 开始对话即可体验

### 分发建议

- 在角色卡说明中注明「本卡支持 Galgame 界面插件，请先安装插件获得最佳体验」
- 附上插件安装链接
- （可选）附上本文档的链接帮助用户入门

## 常见接入问题

### 用户反馈资源加载失败

- 检查 GitHub 仓库是否为 **公开** 仓库
- 检查 `remote_assets.json` 文件是否已正确上传
- 检查 jsDelivr CDN 是否在用户所在地区可访问
- 建议提供备用 CDN 地址

### Live2D 模型不显示

- 确认模型 URL 可公开访问
- 检查是否存在跨域（CORS）问题
- 建议启用 CORS 代理选项

### TTS 没有声音

- TTS 功能依赖用户本地的 TTS 引擎
- 如使用 GPT-SoVITS，用户需自行搭建服务
- 音色绑定信息会随卡分发，但用户需要有对应的音色库

### 配置没有生效

- 确认导出时使用的是「导出角色卡 PNG」功能
- 用户可在资源管理器 → 导入 → 「从当前角色卡导入」手动触发导入
