# 设置面板详解

## 打开设置面板

点击工具栏的 **设置** 按钮（⚙️）即可打开设置面板。

## 面板结构

设置面板分为三个顶部选项卡：

| 选项卡 | 内容 |
|---|---|
| **基础设置** | 所有配置项（文本、显示、特效、立绘、TTS、快捷键、加强模式等） |
| **资源管理** | 资源管理器（立绘、背景、Live2D、地图、图包、皮肤） |
| **关于** | 版权声明、许可协议、法律合规、发布地址 |

## 基础设置详解

基础设置选项卡包含以下区域：

### 主开关

顶部的大按钮用于开启/关闭当前角色卡的 Galgame 模式。这是一个**角色卡独立设置**——不同角色卡可以独立控制。

### 文本显示

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 字体大小 | 对话文字大小（1~30） | 15 |
| 对话字体 | 字体预设（现代黑体/思源宋体/霞鹜文楷/经典楷体/等宽字体） | 现代黑体 |
| 对话框透明度 | 对话框背景透明度 | 50% |
| 文字特效 | 无/阴影增强/发光效果/文字描边/毛玻璃背景/底部渐变遮罩/独立文字背景 | 无 |
| 打字机显示 | 普通对话是否逐字显示 | 开启 |
| 打字速度 | 打字机每秒显示字符数（5~60） | 30 字/秒 |
| 打字音效 | 打字机逐字播放滴答音效 | 开启 |
| 音效音量 | 打字机音效音量（0~100） | 35% |

### 自动播放

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 播放间隔 | 自动播放时每段对话之间的等待时间 | 2 秒 |

### 显示设置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 显示立绘 | 是否显示角色立绘 | 开启 |
| 沉浸模式 | 隐藏其他聊天楼层 | 开启 |
| 背景图填充 | Cover（填满裁剪）或 Contain（完整显示） | Cover |
| 界面皮肤 | 切换主题风格 | 默认 |

### Pixi特效

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 启用特效 | 总开关 | 开启 |
| 质量档位 | Mobile/Balanced/High | Balanced |
| 切场景自动清空 | 切换场景时自动清除特效 | 开启 |
| 并发上限 | 同时运行的特效数 | 2 |

### 立绘设置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 立绘大小 | 整体缩放比例（50%~150%） | 100% |
| 垂直位置 | 底部偏移（0%~50%） | 20% |
| 立绘间距 | 左右距离（0%~20%） | 20% |
| 说话者光晕 | 当前说话角色的轮廓发光 | 开启 |
| 气泡指示器 | 漫画风格对话气泡 | 开启 |

### TTS配音

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 启用TTS配音 | 总开关 | 开启 |
| TTS引擎 | 小白X（豆包火山）/ GPT-SoVITS v2ProPlus | 小白X |
| 自动播放 | 切段自动朗读 | 开启 |
| 默认音色 | 未绑定时的默认音色 | 不指定 |

#### GPT-SoVITS 子配置

选择 GPT-SoVITS 引擎后会展开详细配置：

| 设置项 | 说明 |
|---|---|
| API地址 | 服务地址（默认 `http://127.0.0.1:9880`） |
| 使用酒馆代理 | 通过 SillyTavern CORS 代理 |
| 模型切换模式 | set_weights / set_model / none |
| set_model 接口 | 自定义端点路径 |
| 严格切换 | 切换失败不回退 |
| 模型管理 | 打开可视化管理面板 |
| 音色列表 | JSON 编辑器 |

### 快捷键

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 空格键 → 下一句 | 按空格推进对话 | 开启 |
| 回车键 → 下一句 | 按回车推进对话 | 开启 |
| Ctrl长按 → 快进 | 长按 Ctrl 连续快进 | 开启 |

### 其他设置

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 智能判断主界面显示 | 只有检测到 Galgame 标签才显示界面 | 关闭 |
| 全局Debug日志 | 开启详细调试日志 | 关闭 |
| 快进速度 | Ctrl 快进的速度（0.01s~0.2s） | 0.05s |

### 加强模式

详见 [加强模式](/advanced/enhanced-mode) 章节。

### 刷新视图

底部的「刷新视图」按钮用于强制重新渲染 Galgame 覆盖层。
