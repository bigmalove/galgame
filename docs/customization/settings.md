# 设置面板详解

## 打开设置面板

点击工具栏的 **设置** 按钮（⚙️）即可打开设置面板。

## 选项卡概览

设置面板分为多个选项卡：

### 显示设置

| 设置项 | 说明 |
|---|---|
| 字号大小 | 调整对话文字大小 |
| 对话框透明度 | 调整对话框背景透明度 |
| 文字特效 | 选择无、阴影增强、文字描边、毛玻璃背景等视觉渲染样式 |
| 背景填充模式 | Cover 或 Contain |
| 界面皮肤 | 切换主题风格 |
| 显示立绘 | 是否显示角色立绘 |
| 隐藏其他楼层 | 仅显示最新消息 |

### 音频设置

| 设置项 | 说明 |
|---|---|
| TTS 开关 | 启用/禁用语音合成 |
| TTS 引擎 | 选择小白盒或 GPT-SoVITS |
| 自动播放 | 是否自动播放语音 |
| 角色音色绑定 | 为角色指定音色 |
| GPT-SoVITS 配置 | API 地址、模型等详细设置 |

### 生图配置

| 设置项 | 说明 |
|---|---|
| 背景图来源 | 选择 None/ComfyUI/Banana/NovelAI/Wallhaven |
| 各引擎参数 | 根据所选引擎显示对应的配置项 |

### 资源管理

进入资源管理器，管理立绘、背景、Live2D 等资源。
