# 界面皮肤

## 可用皮肤

插件内置多款主题皮肤，一键切换界面风格：

| 皮肤 | 风格 |
|---|---|
| **默认** | 简洁现代（Cyber Pop） |
| **墨染千秋** | 🏯 中国古风（E-Ink / Paper 风格） |
| **冒险者酒馆** | ⚔️ 西方奇幻 / D&D（支持自定义纹理编辑器） |
| **心之怪盗** | 🎭 女神异闻录风格 |
| **苍穹之庭** | 🗡️ 日式奇幻 / JRPG |
| **樱色物语** | 🌸 经典 Galgame |

## 切换皮肤

1. 打开 **设置面板**
2. 在「显示设置」中找到「界面皮肤」
3. 从下拉列表中选择想要的皮肤
4. 覆盖层会立即切换为新皮肤的视觉风格

## 冒险者酒馆纹理编辑器

选择「冒险者酒馆」皮肤后，可以使用内置的纹理编辑器自定义界面纹理：

- 替换背景纹理（羊皮纸、木头等）
- 调整边框和装饰元素
- 在图片模式和 CSS 模式之间切换

## 皮肤与透明度

每款皮肤都支持对话框透明度调节——透明度值会通过 CSS 变量 `--panel-opacity` 传递给皮肤样式，确保所有皮肤都能正确响应透明度设置。

## 自定义皮肤

你也可以通过资源管理器导入第三方制作的皮肤包。
