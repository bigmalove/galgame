# 界面皮肤

## 可用皮肤

插件内置多款主题皮肤，一键切换界面风格：

| 皮肤 | 风格 |
|---|---|
| **默认** | 简洁现代 |
| **墨染千秋** | 🏯 中国古风 |
| **冒险者酒馆** | ⚔️ 西方奇幻 / D&D |
| **心之怪盗** | 🎭 女神异闻录风格 |
| **苍穹之庭** | 🗡️ 日式奇幻 / JRPG |
| **樱色物语** | 🌸 经典 Galgame |

## 切换皮肤

1. 打开 **设置面板**
2. 在「显示设置」中找到「界面皮肤」
3. 从下拉列表中选择想要的皮肤
4. 覆盖层会立即切换为新皮肤的视觉风格

## 自定义皮肤

你也可以通过资源管理器导入第三方制作的皮肤包。
