# 界面总览

## 覆盖层结构

Galgame 覆盖层是插件的核心界面，它覆盖在 SillyTavern 的聊天区域之上，将 AI 输出渲染为视觉小说画面。

<!-- ![界面结构示意图](../public/images/ui-overview.png) -->

覆盖层由以下区域组成：

| 区域 | 说明 |
|---|---|
| **背景层** | 全屏背景图片，随剧情场景切换 |
| **特效层** | PixiJS 粒子特效（雨、雪、雾等） |
| **立绘槽位** | 左右两侧的角色立绘/Live2D 展示区域 |
| **对话框** | 底部半透明对话框，显示角色名和对话文本 |
| **状态弹窗** | 右上角的地点/时间状态图标 |
| **工具栏** | 底部操作按钮区域 |

## 工具栏按钮

工具栏位于覆盖层底部，提供以下功能：

| 按钮 | 功能 |
|---|---|
| ⚙️ **设置** | 打开设置面板 |
| 📖 **历史** | 查看剧情回顾 |
| 🗺️ **地图** | 打开地图系统 |
| 🔊 **BGM** | 背景音乐播放/暂停 |
| ▶️ **自动播放** | 开启/关闭自动推进对话 |
| ⏭️ **下一步** | 推进到下一段对话 |
| 🔲 **全屏** | 进入/退出全屏模式 |

## 打开和关闭覆盖层

- **打开**：点击聊天区域右下角的 Galgame 按钮
- **关闭**：再次点击该按钮，或在覆盖层内按 `Esc`

## 全屏模式

点击工具栏的 **全屏** 按钮，覆盖层将扩展至浏览器全屏，获得更沉浸的体验。

再次点击或按 `Esc` 可退出全屏。

## 快捷键

插件支持以下快捷键（可在设置面板中开关）：

| 快捷键 | 功能 | 默认状态 |
|---|---|---|
| `空格` | 推进到下一段对话 | 开启 |
| `回车` | 推进到下一段对话 | 开启 |
| `Ctrl` 长按 | 快进模式（连续推进） | 开启 |
