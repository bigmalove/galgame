# COT 模板

## 什么是 COT 模板

COT（Chain of Thought）模板是插件自动生成的一段提示词，它告诉 AI 应该以什么格式输出内容。

这段提示词会被写入一个专用的世界书（`galgame界面插件`），条目名为「Galgame输出格式规范」，并以「系统提示」的方式注入到 AI 的上下文中。

## 自动生成的内容

COT 模板会根据你当前的配置自动生成，包含：

- ✅ 所有可用的表情列表（含自定义表情）
- ✅ 背景场景列表（根据你上传的背景图）
- ✅ TTS 音色列表和角色绑定关系
- ✅ 背景图来源的使用规范（本地/ComfyUI/大香蕉/NovelAI/Wallhaven）
- ✅ 特效标签使用规则
- ✅ BGM 白名单
- ✅ 输出格式示例

::: info TTS 状态会影响输出格式
开启 TTS 时，COT 模板会指示 AI 使用 `角色名[表情,音色]` 格式。
关闭 TTS 时，会使用简单的 `角色名: "对话"<表情名>` 格式。
:::

## 注入世界书

1. 打开 **设置面板**
2. 开启 Galgame 模式时会自动注入
3. 也可以手动触发：修改 TTS 设置或音色列表时，插件会自动重新注入

::: tip
每次你修改了资源（如添加/删除立绘、背景、音色绑定），建议确保世界书已更新。开关 TTS、切换 TTS 引擎、保存音色列表时，COT 会自动更新。
:::

## 需要重新注入的场景

当你更改了以下配置后，需要确保 COT 已更新：

- 添加/删除/修改表情差分
- 上传/删除背景图
- 修改 TTS 音色绑定
- 切换背景图来源
- 修改 BGM 白名单
- 切换 TTS 引擎
