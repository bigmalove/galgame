# 常见问题

## 覆盖层不显示

**可能原因**：
- 未安装酒馆助手插件
- 脚本未加载成功（检查控制台是否有报错）
- 当前角色卡未开启插件

**解决方法**：
1. 确认酒馆助手已安装且启用
2. 检查脚本列表中「galgame界面插件」是否存在且启用
3. 按 F12 查看控制台是否有加载错误

## AI 不按 Galgame 格式输出

**可能原因**：
- 未注入 COT 世界书
- 模型能力不足以遵守格式

**解决方法**：
1. 在设置面板中点击「注入世界书」
2. 如果仍不行，启用 [加强模式](/advanced/enhanced-mode)

## 立绘/背景不加载

**可能原因**：
- 未上传对应的资源
- 远程资源地址不可访问

**解决方法**：
1. 检查资源管理器中是否有对应的立绘/背景
2. 如果使用远程资源，检查 URL 是否可访问

## Live2D 模型网络错误

**可能原因**：
- 远程模型 URL 存在跨域（CORS）限制
- 网络不稳定

**解决方法**：
1. 在 Live2D 设置中启用 CORS 代理
2. 将模型上传到支持跨域的 CDN（如 jsDelivr）
3. 或改为本地上传模型

## TTS 没有声音

**可能原因**：
- TTS 未启用
- 音色未绑定
- GPT-SoVITS 服务未运行

**解决方法**：
1. 检查设置面板中 TTS 是否开启
2. 确认角色已绑定音色
3. 如果使用 GPT-SoVITS，确认本地服务正在运行

## 移动端显示异常

**说明**：
插件针对桌面浏览器优化，在移动端可能存在布局适配问题。

**建议**：
- 使用全屏模式获得更好的体验
- 如果弹窗被遮挡，尝试横屏使用
