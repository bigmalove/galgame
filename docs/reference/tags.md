# AI 输出标签速查

::: info
你通常不需要手写这些标签——注入 COT 世界书后，AI 会自动使用正确的格式。本页仅供参考和排障。
:::

## 结构标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<maintext>` | 包裹所有内容的根标签 | `<maintext>...</maintext>` |

## 对话标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<p>` | 一段对话或旁白 | `<p>旁白内容</p>` |
| `<p>角色名[表情]: "对话"</p>` | 角色对话（含表情，TTS 开启时） | `<p>少女[微笑]: "你好呀～"</p>` |
| `<p>角色名[表情,音色]: "对话"</p>` | 角色对话（首次指定音色） | `<p>少女[微笑,桃夭]: "你好～"</p>` |
| `<p>角色名[表情\|语气描述]: "对话"</p>` | 角色对话（含语气指导） | `<p>少女[微笑\|温柔地]: "你好～"</p>` |

### TTS 启用时的格式

```
<p>角色名[表情]: "对话内容"</p>
<p>角色名[表情,音色]: "对话内容"</p>
<p>角色名[表情|语气描述]: "对话内容"</p>
```

### TTS 未启用时的格式

```
<p>角色名: "对话内容"<表情名></p>
```

## 场景标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<background>` | 设置背景场景 | `<background scene="教室" />` |
| `<bgimg>` | AI 生图标签（ComfyUI/NovelAI） | `<background scene="森林"><bgimg>tags...</bgimg>` |
| `<bnimg>` | 大香蕉生图标签 | `<background scene="森林"><bnimg>描述...</bnimg>` |
| `<whimg>` | Wallhaven 搜索标签 | `<background scene="森林"><whimg>forest, night</whimg>` |

## 特效标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<pixiPerform>` | 播放特效 | `<pixiPerform name="rain" />` |
| `<pixiInit>` | 清空所有特效 | `<pixiInit />` |

可用特效名：`rain`、`snow`、`heavySnow`、`cherryBlossoms`、`fog`、`fireflies`、`embers`、`screenFlash`

## 音频标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<bgm>` | 播放背景音乐 | `<bgm>歌曲名</bgm>` |

::: tip
`<bgm>` 标签也支持 `当前bgm:歌曲名` 的格式，插件会自动提取实际歌曲名。
:::

## 交互标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<option>` | 选项 | `<option id="1">选项文字</option>` |

## 状态标签

| 标签 | 说明 | 示例 |
|---|---|---|
| `<弹窗一>` | 位置状态 | `<弹窗一>教室</弹窗一>` |
| `<弹窗二>` | 时间状态 | `<弹窗二>放学后</弹窗二>` |

## 完整示例

```html
<maintext>
  <background scene="雨夜街道" />
  <pixiPerform name="rain" />
  <p>夜色深沉，街灯在雨中摇曳。</p>
  <p>少女[微笑]: "你终于来了～"</p>
  <bgm>夜的钢琴曲</bgm>
  <p>她撑着伞，静静地站在那里。</p>
  <p>少女[惊讶]: "下这么大的雨，你怎么不带伞？"</p>
  <弹窗一>商业街路口</弹窗一>
  <弹窗二>晚上 9:00</弹窗二>
</maintext>
```
