# 资源管理器

## 打开资源管理器

在 **设置面板** 中点击「资源管理」选项卡即可打开资源管理器。

## 资源分类

| 分类 | 内容 |
|---|---|
| **立绘** | 角色立绘图片（含表情差分） |
| **背景** | 场景背景图片 |
| **Live2D** | Live2D 模型文件 |
| **地图** | 地图背景图片 |
| **图包** | 资源图包（可打包多种资源） |
| **UI 皮肤** | 界面主题皮肤 |

## 基本操作

每种资源都支持：

- 📤 **上传** —— 添加新资源
- 👁️ **预览** —— 查看已有资源
- 🗑️ **删除** —— 移除不需要的资源
- ✏️ **编辑** —— 修改资源属性（名称、标签等）

## 图包系统

图包是一组资源的集合，可以方便地打包和切换：

- **创建图包**：将当前资源打包
- **导入图包**：从文件或远程地址导入
- **切换图包**：一键切换活跃的资源包
- **远程图包**：配置远程地址后，资源可从 CDN 按需加载

## 生图配置

资源管理器中还包含「生图配置」面板，用于配置 AI 实时生成背景的参数。支持的生图引擎包括：

- **ComfyUI** —— 连接本地 ComfyUI 服务
- **大香蕉 (Banana)** —— 在线 AI 生图服务
- **NovelAI** —— NovelAI 图像生成 API
- **Wallhaven** —— Wallhaven 壁纸搜索

详细配置说明请参见 [背景与场景](/basics/backgrounds) 章节。
