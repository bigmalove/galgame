## 如何导入

1. 打开 **资源管理器**
2. 点击右上角 **导入 → 内置背景图包**
3. 可先点 **预览** 查看某个图包的全部缩略图
4. 点 **一键导入**，完成后可选择切换为当前图包

::: tip 网络说明
默认走 `cdn.jsdelivr.net`，获取失败时自动切换 `gcore.jsdelivr.net` 镜像（大陆可用）。
:::

## 同名场景的覆盖行为

背景以**场景名**为唯一标识。如果你已有同名背景（例如自己上传过「教室」），导入内置图包会**覆盖**它并把该场景移入内置图包。导入前会弹出确认列表，可取消。

## 手动导入（不走内置入口）

内置图包就是标准的远程图包，也可以在 **导入 → 导入远程链接JSON** 中直接粘贴 manifest 地址：

```
https://cdn.jsdelivr.net/gh/bigmalove/galgame-bg-jp@v1.3.0/remote_assets.json
https://cdn.jsdelivr.net/gh/bigmalove/galgame-bg-xianxia@v1.3.0/remote_assets.json

https://cdn.jsdelivr.net/gh/bigmalove/galgame-bg-city@v1.3.0/remote_assets.json
```

**立绘模板不会自动入库**——它是给你自己的角色用的素材：

1. 打开角色的 **上传立绘** 弹窗 → 切到 **内置模板** tab
2. 确认上方角色名（即你剧情里的角色）→ 选一套模板点 **套用**
3. 整套 10 个表情以远程链接引用挂到该角色名下（不占本地存储）；同一模板可被多个角色重复套用

**路人剪影**（路人 / 路人男 / 路人女）在导入图包时自动入库：剧情中出现**没有立绘的角色**时自动以剪影显示（按对白声线匹配性别），避免空场。不想要此行为可在立绘管理中删除路人立绘。

## 自制第三方图包

照同样的格式即可做自己的远程图包：

1. GitHub 仓库放 `backgrounds/<场景名>.webp`（建议 16:9、≤800KB/张，中文文件名可用）
2. 仓库根放 `remote_assets.json`：

```json
{
  "packageName": "我的图包",
  "backgrounds": [
    {
      "sceneName": "教室",
      "url": "https://cdn.jsdelivr.net/gh/<user>/<repo>@<tag>/backgrounds/%E6%95%99%E5%AE%A4.webp"
    }
  ]
}
```

3. 打 release tag（jsDelivr 对 tag 永久缓存；`@main` 有 12 小时缓存延迟）
4. 在插件中用「导入远程链接JSON」填入 manifest 地址

::: warning jsDelivr 限制
单文件 20MB、单仓库（每个 tag）50MB。16 张 2K webp 约 7-8MB，余量充足。
:::
