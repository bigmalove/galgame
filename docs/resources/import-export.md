# 导入与导出

## 配置导出

在资源管理器的 **导出** 菜单中，你可以：

| 导出项 | 说明 |
|---|---|
| **导出角色卡配置 JSON** | 将当前所有配置导出为 JSON 文件 |
| **导出角色卡 PNG** | 将配置嵌入角色卡 PNG 中，分享给其他用户 |
| **导出远程资源包** | 生成 `remote_assets.json`，用于远程托管 |

## 配置导入

在资源管理器的 **导入** 菜单中：

| 导入项 | 说明 |
|---|---|
| **从角色卡导入** | 自动读取当前角色卡中嵌入的配置 |
| **从 JSON 导入** | 手动导入配置文件 |

## 远程资源

如果你的资源托管在远程服务器（如 GitHub）：

1. 在资源管理器中填写远程地址
2. 支持 GitHub 仓库地址自动转换为 jsDelivr CDN
3. 资源会按需从远程加载，本地缓存

::: tip
GitHub 地址格式：`https://github.com/用户名/仓库名`，插件会自动转换为 CDN 加速链接。
:::
